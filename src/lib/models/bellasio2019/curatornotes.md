The model shows discrepancies between the paper's description and the provided Excel Worksheet. However, the latter is deemed to be the absolute truth. Still, some figures in the publication are inconsistently reproduced. After deeper analysis, it is assumed the errors mostly come from the implementation of $J_\mathrm{ATP}$ and $J_\mathrm{NADPH}$, as the mathematical expressions cannot be truly replicated inside a continuous integration solver. Additionally, the simulation used for each figure is not given in full detail, so thoughtful assumptions had to be made to fulfill the replications. Even if some figures are not fully reproduced, others are. Therefore, caution is advised when using this version of the model, and any support towards a better implementation is encouraged.
