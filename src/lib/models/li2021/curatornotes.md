The model itself is not fully represented in the publication, however, there is an open source repository that contains the model code. However, the code for the simulations to recreate the figures of the publication is not provided. Many of the reproduced figures are not fully consistent with the publication, and some of the discrepancies are likely due to the lack of information on the simulation setup. The available code is also not fully documented and written in a cleanly shareable way, which makes it difficult to understand and use. Therefore, caution is advised when using this version of the model, and any support towards a better implementation is encouraged.
